# Proyecto Java - Interfaces y Roles Empresariales

## Descripción
Este repositorio contiene el desarrollo de tres ejercicios prácticos en Java enfocados en el uso de interfaces, implementación de métodos, validaciones y manejo de roles dentro de distintos sistemas.

Los proyectos fueron desarrollados aplicando principios básicos y avanzados de Programación Orientada a Objetos (POO).

---

# Contenido del Proyecto

## Tarea 1: Sistema académico de documentos
Sistema para imprimir distintos documentos académicos utilizando una interfaz común.

### Clases implementadas
- Imprimible
- Certificado
- ActaNotas
- HorarioAcademico
- MainAcademico

### Funcionalidades
- Implementación de interfaces
- Uso de @Override
- Mensajes personalizados
- Atributos propios para cada documento

---

## Tarea 2: Sistema bancario de pagos
Sistema bancario que procesa pagos mediante diferentes métodos.

### Clases implementadas
- Pagable
- PagoEfectivo
- PagoTarjeta
- Transferencia
- MainPagos

### Funcionalidades
- Validación de montos
- Comisiones bancarias
- Diferentes métodos de pago
- Reutilización de lógica

---

## Tarea 3: Sistema de roles empresariales
Sistema empresarial con autenticación y control de permisos mediante múltiples interfaces.

### Clases implementadas
- Autenticable
- Reportable
- Gestionable
- Cajero
- Administrador
- Supervisor
- MainEmpresa

### Funcionalidades
- Inicio de sesión
- Validación de usuario y contraseña
- Generación de reportes
- Gestión de información
- Menú interactivo
